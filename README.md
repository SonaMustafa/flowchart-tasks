# Flowchart Tasks

## Description
This repository contains flowcharts created as part of a homework assignment. The diagrams represent everyday situations and simple decision-making algorithms.

## Tasks
- **Morning Routine:** A flowchart showing the morning routine, including weather conditions and weekends.
- **ATM:** A flowchart illustrating PIN verification, balance checking, and cash withdrawal.
- **Cinema Ticket:** A flowchart for calculating ticket prices based on age and student status.
- **FizzBuzz:** A flowchart demonstrating divisibility rules for the numbers 3 and 5.
